# Materiały Google Play — nowy projekt

Pakiet: `pl.jezykikrokpokroku.app`

Nazwa: **Języki Krok po Kroku**

Ten katalog dotyczy wyłącznie nowej aplikacji wielokursowej. Nie zawiera
artefaktów, certyfikatów, zrzutów ani opisów dawnej aplikacji szwedzkiej.

Przed publikacją trzeba przygotować nowe zrzuty ekranu, grafikę funkcji,
podpisany AAB, publiczny adres polityki prywatności i właściwy klucz wysyłania.
Aktualny build `0.1.0+1` jest wersją rozwojową i nie został przesłany do Google
Play.
